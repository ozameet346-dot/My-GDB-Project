## 📝 Project Description

The project is an interactive **Personal Data Collector** written in Python.

The program asks the user to enter personal information and then displays the collected information along with Python data types and memory addresses.

### The program collects:

* 👤 Name
* 🎂 Age
* 📏 Height
* 🔢 Favourite Number

It also performs calculations based on the entered information and demonstrates Python's built-in functions such as:

* `input()`
* `int()`
* `float()`
* `type()`
* `id()`
* `print()`

## 🚀 How to Run

### Method 1 — OnlineGDB

1. Open the **[Live Project](https://onlinegdb.com/XBVO7qyYi)**.
2. Click **Run**.
3. Enter the requested information in the console.
4. View the program output.

### Method 2 — Run Locally

Make sure Python is installed on your computer.

Clone the repository:

```bash
git clone https://github.com/ozameet346-dot/My-GDB-Project.git
```

Move into the project folder:

```bash
cd My-GDB-Project
```

Run the Python file:

```bash
python 01_exam.py
```
